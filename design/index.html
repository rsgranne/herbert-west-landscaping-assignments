Design guide for Herbert West Landscaping

How to use this guide

This guide describes the intended visual design of the finished Herbert West Landscaping website. We will build that design gradually.

During the HTML portion of the course, focus on meaningful content and semantic structure. Once we get to CSS, use this guide’s color, typography, spacing, and component decisions. After we start responsive design using Bootstrap, use it to guide layout and behavior at different screen sizes.

Bootstrap is an implementation tool. It can help us build the design efficiently, but it does not replace the design decisions documented here.

Course stage What students use from this guide
HTML Content, semantic structure, heading hierarchy, page purpose, and image/alt-text decisions
CSS Color, typography, spacing, borders, cards, and other visual rules
Responsive design Grid, breakpoints, responsive behavior, and component implementation
