 Minimum Technical Requirements

Your computer needs to have a modern web browser installed:

  • a Chromium-based browser
    • This includes Chrome & the new Edge (pre-installed on Windows 10 & 11)…
    • …but I would recommend giving Brave a try — it’s just like Chrome & Edge, but without the corporate surveillance & data mining (supposedly Canvas works best in a Chromium-based browser, but if you like Firefox or Safari, try those & let me know)
    • If you decide to install & test Brave (& why not — it’s free!), I strongly recommend going through a presentation I created about Brave which is available on my website. It tells you how to configure everything & how to get the most out of the web browser.
  • Firefox (Links to an external site.)
  • Safari comes pre-installed on all Macs
  • You do not need Lockdown browser, because I would never require you to use that thing

The Tech Readiness page identifies the browsers, operating systems, & plug-ins that work best with Canvas.

I will tell you about other software as it is needed.

 Required Computer Skills

As far as technical skills, you should know how to do the following:

  • use your file manager (Finder on macOS & File Explorer on Windows) to create files & folders, & copy & paste files & folders; in addition, you should understand how a folder structure works
  • understand how to find files, folders, & programs on your computer
  • install software
  • use a Web browser
  • zip (compress or archive) & unzip (unarchive) files & folders
  • work with multiple programs, & multiple windows, open at the same time
