Once we are creating responsive webpages, it will be imperative that we test our work in Live Preview as we go. Grab the right edge of your Web browser’s window & slowly move it to the left so that you narrow the wide desktop window down to a narrow phone width. Then go slowly back to a wide window.

NOTE: This is a really great reason why you should never run your browser maximized or in full screen mode! I don't care if you're on Windows or Mac or Linux, do not run your browsers maximized.

Number one, it makes it really hard to change the window size. Number two, you end up reading text running full width with a very long line, and that is almost always a bad way to read text. Number three, you should be able to resize the browser’s window so that it is at the optimal width to view each website as needed.

Therefore, do not keep your browser windows maximized or in full screen mode!

As you resize the browser window while viewing the webpage in Live Preview, look for these things:

  • Text is readable and does not run off the edge of the viewport
  • Images resize without becoming wider than their containers
  • Multi-column content rearranges or stacks when there is not enough room
  • Navigation and the footer remain usable at narrower widths
  • Spacing does not become cramped or awkward at smaller or larger widths

When something does not work as expected, we will figure out why, look for a solution, and test it again until it’s correct. Sometimes we will find that Bootstrap already gives us exactly what we need. Sometimes we will need to make changes so that a Bootstrap component works the way we want it to work.
